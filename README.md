# Kripto Uyum Pusulası

Türkiye’de kripto varlık platformları ve saklama kuruluşları için SPK, MASAK
ve operasyonel uyum başlıklarını bir araya getiren bilgilendirme sitesi.

## Yerel geliştirme

Node.js 22 veya üzeri ile:

```bash
npm install
npm run dev
```

Üretim derlemesini doğrulamak için:

```bash
npm run build
```

## Vercel

GitHub reposunu Vercel’e bağlarken:

- Framework Preset: `Next.js`
- Root Directory: `./`
- Build Command: varsayılan (`next build`)
- Output Directory: varsayılan
- Install Command: varsayılan

Ek ortam değişkeni gerektirmez.
